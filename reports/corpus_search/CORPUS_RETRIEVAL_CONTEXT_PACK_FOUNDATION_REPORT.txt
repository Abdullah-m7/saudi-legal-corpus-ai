CONTEXT_PACK_SCOPE
================================================================

A local retrieval context pack generator that:
- Takes a query
- Runs deterministic lexical search (existing local search)
- Exports top N results as structured evidence/context pack
- Supports JSON and Markdown output formats
- Includes full provenance for each record
- Does NOT generate answers, interpret, summarize, or reason
