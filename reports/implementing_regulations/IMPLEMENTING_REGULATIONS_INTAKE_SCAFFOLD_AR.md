# تقرير: scaffold استيعاب اللائحة التنفيذية لنظام الشركات السعودي

## المرحلة

scaffold استيعاب (Intake Scaffold) — قراءة فقط؛ لا يستوعب نصًا عربيًا رسميًا،
ولا يُنشئ ترجمة إنجليزية أو صينية، ولا محاذاة ثلاثية اللغة، ولا إصدارًا عامًا.

## السياق

يوفّر هذا scaffold بنية نظيفة لاستقبال اللائحة التنفيذية لنظام الشركات السعودي
(م/132، 1443هـ) كـ **مسار مستقل** ضمن المستودع، مع الحفاظ على فصل واضح بين
النظام (Companies Law) واللائحة التنفيذية.

## الهيكل المقترح

```
data/implementing_regulations/
  intake_scaffold.json          ← بيانات scaffold الوصفية (هذا الملف)
  README.md                     ← دليل scaffold
```

### الدلائل المستقبلية (غير منشأة بعد)

```
data/implementing_regulations/official_arabic/     ← استيعاب النص العربي الرسمي
data/implementing_regulations/arabic_legal_llm/   ← طبقة العربية LLM-ready
data/implementing_regulations/english_reference/  ← طبقة إنجليزية مرجعية
data/implementing_regulations/english_legal_llm/   ← طبقة إنجليزية LLM-ready
data/implementing_regulations/chinese_internal/   ← طبقة صينية مرجعية داخلية
```

## محتوى scaffold

ملف `intake_scaffold.json` يحتوي على:

- **بيانات المنشأ (source provenance):** حقول فارغة تنتظر الاستيعاب (URL، الجريدة الرسمية، التاريخ، رقم الإصدار، طريقة الاستيعاب، حالة التحقق)
- **ترقيم المواد (article numbering):** مخطط غير محدد حتى الاستيعاب (العدد الإجمالي، نمط الترقيم، النطاق)
- **طبقات اللغة (language layers):** العربية (حاكمة، غير مستوعبة بعد)، الإنجليزية (مرجعية/إرشادية، غير مضافة بعد)، الصينية (مرجعية داخلية، غير مضافة بعد)
- **حالة التحقق (validation status):** scaffold مُتحقق منه فقط؛ الاستيعاب والطبقات غير مُتحققة
- **حدود الحالة القانونية (legal-status boundaries):** العربية حاكمة، الإنجليزية مرجعية فقط، الصينية مرجعية داخلية فقط، ليست رسمية/ملزمة/حاكمة، ليست استشارة قانونية
- **نموذج المراجعة (review model):** مالك المستودع لديه خلفية قانونية (بكالوريوس في القانون)، مراجعة قانونية نشطة، المراجعة الخارجية اختيارية

## الترتيب المقترح للاستيعاب المستقبلي

1. استيعاب النص العربي الرسمي للائحة التنفيذية من المصدر الرسمي (أم القرى أو boe.gov.sa)
2. التحقق من المصدر وإثبات المنشأ
3. إنشاء طبقة العربية LLM-ready
4. إضافة الإنجليزية كطبقة مرجعية/إرشادية (اختياري)
5. إضافة الصينية كطبقة مرجعية داخلية (اختياري)

## الحدود القانونية / الرسمية

- **اللائحة التنفيذية مسار مستقل** عن النظام (Companies Law corpus)
- **النص العربي الرسمي حاكم**
- **الإنجليزية، إن أُضيفت لاحقًا، مرجعية/إرشادية فقط**
- **الصينية، إن أُضيفت لاحقًا، مرجعية داخلية فقط**
- **ليست رسمية، ليست ملزمة، ليست حاكمة**
- **ليست استشارة قانونية**
- **لا تعديل للنظام أو برنامج المعالجة الصينية المكتمل**

## الحالة النهائية

**SCAFFOLD_ONLY** — scaffold استيعاب اللائحة التنفيذية منشأ ومُتحقق منه؛
لا استيعاب نص بعد، ولا طبقات لغة بعد، ولا إصدار عام.
