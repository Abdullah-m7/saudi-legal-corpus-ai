## 4. الحدود القانونية

- ✓ النص العربي الرسمي هو الحاكم
- ✓ ليست ترجمة رسمية
- ✓ ليست استشارة قانونية
- ✓ لا يوجد توليف ثلاثي اللغات
- ✓ لا يوجد إصدار عام
- ✓ الإنجليزية (إذا أُضيفت لاحقاً) مرجع/إرشاد فقط
- ✓ الصينية (إذا أُضيفت لاحقاً) مرجع داخلي فقط
- ✓ المساران منفصلان
- ✓ المسار المتخصص ليس عاماً
