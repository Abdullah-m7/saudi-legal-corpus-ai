# Journal Manuscript — Language Resources and Evaluation (Springer)

Journal version of the corpus resource paper. This is a **separate, expanded
manuscript**, not a reformat of the conference version in `../latex/`:
single-column Springer layout, decimal headings (three levels max, per the
journal's instructions), fuller prose throughout, a new coverage-by-domain
section, and the Springer-required Declarations block.

| File | Purpose |
|---|---|
| `main.tex` | The manuscript. Uses `sn-jnl.cls` when present, else a self-contained fallback. |
| `references.bib` | Bibliography (kept identical to the conference version). |
| `example_record.png` | Figure 1 (generated by `../latex/gen_example_record_figure.py`). |
| `main.pdf` | Compiled manuscript (13 pages in the fallback layout). |
| `cover_letter.md` | Cover letter to paste into Editorial Manager at submission. |

## Target venue

**Language Resources and Evaluation** (Springer) — the journal of record for
language resources, and the closest fit for a corpus/benchmark paper.
Journal home: <https://link.springer.com/journal/10579>
Submission system: <https://www.editorialmanager.com/lrev/>

Springer recommends preparing the manuscript with its own LaTeX template;
Overleaf's Springer Nature template also offers a direct "Submit to journal"
action. Author contributions and competing interests must be entered through
the submission interface, not only in the manuscript — the interface values
are what get published.

*Artificial Intelligence and Law* (Springer) is the intended venue for the
follow-up paper on the legislative citation network, not for this one.

## Build

```
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

`sn-jnl.cls` is distributed by Springer (and preinstalled on Overleaf), not
via CTAN. Drop it next to `main.tex` — or open the project from Springer's
Overleaf template — and the preamble switches to it automatically. Without
it, the fallback single-column layout compiles on a plain TeX Live install
(`texlive-latex-base`, `-latex-recommended`, `-fonts-recommended`).

      resolution requirements on its submission-guidelines page.

## Note on dual submission

A manuscript under review at a journal must not be under review at a
conference at the same time. Posting the preprint on arXiv is compatible
with both.
