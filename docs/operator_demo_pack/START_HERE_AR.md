# دليل البدء السريع — حزمة عرض المشغل

## ما هذا العرض؟

هذه حزمة عرض توضيحي محلية لسير عمل استرجاع السجل القانوني السعودي. تتيح لك تشغيل سيناريوهات استرجاع منظمة على ٤٥٠ سجلًا عربيًا حاكمًا (نظام الشركات + اللوائح التنفيذية) باستخدام أدوات محلية حتمية فقط.

## ما هو ليس كذلك

- ليس RAG (توليد معزز بالاسترجاع)
- لا يستدعي نماذج لغوية (LLM)
- لا يولد إجابات قانونية
- لا يقدم استشارة قانونية
- لا يفسر نصوصًا قانونية
- لا يحكم على الصحة القانونية
- لا يتحقق الدعم الدلالي
- لا ينشئ تضمينات أو بحثًا دلاليًا أو API أو واجهة أو قاعدة بيانات
- لا يستخدم الشبكة
- لا ينتج عنه إصدار عام

## البدء السريع (٣ أوامر)

```bash
# 1. التحقق من الجاهزية
make corpus-retrieval-demo-scenarios-validate

# 2. تشغيل جميع السيناريوهات الستة
python3 scripts/run_retrieval_demo_scenarios.py

# 3. تشغيل سيناريو يدوي واحد
python3 scripts/run_retrieval_workflow.py "مجلس الإدارة" \
  --mode prepare_prompt --limit 3 --prompt-mode evidence_brief \
  --formats both --output-dir /tmp/corpus_demo_board
```

## ملخص المخرجات المتوقعة

- حزمة سياق (JSON + Markdown) تحتوي على السجلات المسترجعة
- حزمة طلب (JSON + Markdown) تحتوي على قالب طلب آمن
- بيان سير عمل (JSON) يحتوي على البيانات الوصفية الكاملة
- ملف README يشرح محتويات دليل المخرجات

## أين تذهب المخرجات المولدة

جميع مخرجات سير العمل تذهب إلى أدلة مؤقتة فقط (`/tmp/` أو دليل يحدده المستخدم). لا تُلتزم أي مخرجات مولدة في المستودع.

## ما الذي تعرضه

- استرجاع سجلات قانونية عربية بناءً على استعلامات معجمية
- حزم سياق جاهزة للاستخدام في خطوات مستقبلية
- قوالب طلبات آمنة مع قواعد صارمة
- فحص استشهادات ميكانيكي
- سير عمل متكامل من الاستعلام إلى الطلب

## ما لا تقوله

- لا تقل "إجابة قانونية" — النظام لا يولد إجابات
- لا تقل "استشارة قانونية" — النظام لا يقدم استشارة
- لا تقل "ترجمة رسمية" — النظام لا يترجم
- لا تقل "صحة قانونية" — النظام لا يحكم على الصحة
- لا تقل "دعم دلالي" — النظام لا يتحقق الدعم الدلالي
- لا تقل "إصدار عام" — النظام للعرض المحلي فقط
