# سكربت العرض — حزمة عرض المشغل

**المدة المتوقعة:** ٥–٧ دقائق

---

## ١. المشكلة (٣٠ ثانية)

البحث في النصوص القانونية السعودية يدويًا بطيء وعرضة للخطأ. نحتاج أداة محلية حتمية تسترجع السجلات ذات الصلة من نظام الشركات ولوائحه التنفيذية بسرعة ودقة.

## ٢. الأساس القانوني للسجل (٤٥ ثانية)

تم بناء سجل قانوني عربي محكم من ٤٥٠ سجلًا حاكمًا:
- نظام الشركات: ٢٨١ سجلًا
- اللوائح التنفيذية العامة: ٩٩ سجلًا
- اللوائح التنفيذية للشركات المساهمة المدرجة: ٧٠ سجلًا

جميع السجلات عربية، مصدرها رسمي، ومستبعد منها الإنجليزية والصينية. المصدر العربي هو الحاكم.

## ٣. البحث المحلي (٤٥ ثانية)

```bash
python3 scripts/search_primary_arabic_export.py "مجلس الإدارة" --limit 5
```

بحث معجمي حتمي. لا تضمينات، لا شبكة، لا API. النتائج مرتبة بدرجة مطابقة مستقرة. يمكن تصفية النتائج بالمسار أو نوع السجل.

## ٤. حزمة السياق (٣٠ ثانية)

```bash
python3 scripts/build_retrieval_context_pack.py "مجلس الإدارة" --limit 3 --format both --output /tmp/corpus_demo
```

تحول السجلات المسترجعة إلى حزمة سياق منظمة (JSON + Markdown) مع نسب كامل ومقتطفات. هذا تغليف، ليس استدلالًا.

## ٥. حزمة الطلب (٣٠ ثانية)

```bash
python3 scripts/build_retrieval_prompt_pack.py "مجلس الإدارة" --limit 3 --prompt-mode evidence_brief --format both --output /tmp/corpus_demo
```

تبني حزمة السياق إلى قالب طلب آمن بثلاثة أوضاع: موجز أدلة، مسودة إجابة حذرة، فحص استشهادات. القالب يشتمل على قواعد صارمة: استخدم السجلات المسترجعة فقط، استشهد بمعرف السجل، لا تقدم استشارة قانونية.

## ٦. فاحص الاستشهادات (٣٠ ثانية)

```bash
python3 scripts/check_citation_support.py --prompt-pack /tmp/corpus_demo/prompt_pack.json --draft-answer-file /tmp/draft.md
```

فحص ميكانيكي للإشارات في مسودة نص. يتحقق أن كل معرف سجل مذكور موجود فعلًا في الحزمة. ليس تحققًا دلاليًا أو قانونيًا.

## ٧. سير العمل المتكامل (٤٥ ثانية)

```bash
python3 scripts/run_retrieval_workflow.py "مجلس الإدارة" \
  --mode prepare_prompt --limit 3 --prompt-mode evidence_brief \
  --formats both --output-dir /tmp/corpus_demo_board
```

سير عمل واحد يشغل البحث وحزمة السياق وحزمة الطلب ويكتب بيانًا كاملًا. وضعان: تجهيز طلب وفحص مسودة. تزامن رفيع فوق أدوات موجودة — لا تكرار منطق.

## ٨. سيناريوهات العرض (٤٥ ثانية)

```bash
python3 scripts/run_retrieval_demo_scenarios.py
```

٦ سيناريوهات عربية منظمة تغطي:
- مجلس الإدارة (بحث عام)
- الجمعية العامة (قالب إجابة حذرة)
- التصفية (مرشح مسار نظام الشركات)
- الأسهم (مرشح مسار الشركات المساهمة المدرجة)
- النماذج (مرشح نوع السجل: نموذج)
- التوكيل (مرشح نوع السجل: ملحق، نص كامل)

## ٩. الحدود (٣٠ ثانية)

- المصدر العربي الرسمي يحكم
- ليست استشارة قانونية
- ليست ترجمة رسمية
- لا تفسير قانوني
- لا استنتاجات قانونية مولدة
- لا حكم على الصحة القانونية
- لا تحقق الدعم الدلالي
- لا استدعاء LLM
- لا RAG
- لا إصدار عام
- مراجعة قانونية من مالك المستودع نشطة؛ المراجعة القانونية الخارجية اختيارية للاعتماد المؤسسي أو الرسمي

## ١٠. الخطوة التالية نحو RAG المستقبلية (١٥ ثانية)

هذه الأساس يثبت أن خط الاسترجاع يعمل محليًا وحتميًا. الخطوة المستقبلية قد تشمل RAG مع نماذج لغوية — لكن ذلك مرحلة منفصلة، تستوجب مراجعة قانونية إضافية، ولا تُدعى هنا.
