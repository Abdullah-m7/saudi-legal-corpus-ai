## ٢. ما هو جاهز محليًا الآن

المسار الكامل لعرض المشغل المحلي متاح وجاهز للتدريب:

- **تصدير السجلات:** ٤٥٠ سجلًا عربيًا حاكمًا (نظام الشركات + اللوائح التنفيذية)
- **بحث محلي:** بحث معجمي حتمي بدون شبكة (`scripts/search_primary_arabic_export.py`)
- **تقييم البحث:** ١٠٠ حالة تقييم ثابتة (`make corpus-retrieval-local-search-eval`)
- **حزمة السياق:** تغليف السجلات المسترجعة في JSON + Markdown
- **حزمة الطلب:** قوالب طلبات آمنة بثلاثة أوضاع (موجز أدلة، مسودة إجابة حذرة، فحص استشهادات)
- **فاحص الاستشهادات:** فحص ميكانيكي للإشارات في المسودة
- **سير العمل المتكامل:** أمر واحد يشغل البحث → حزمة السياق → حزمة الطلب → بيان سير العمل
- **سيناريوهات العرض:** ٦ سيناريوهات عربية منظمة تغطي حالات مختلفة
- **حزمة عرض المشغل:** أدلة تشغيل وحدود وسكربت عرض وقائمة مراجعة

## ٣. سير عمل العرض المحلي بمصطلحات المشغل

```
تصدير ← بحث ← تقييم ← حزمة سياق ← حزمة طلب ← فاحص استشهادات ← سير عمل ← سيناريوهات عرض ← حزمة عرض المشغل
```

كل خطوة حتمية، محلية، بدون شبكة، بدون نماذج لغوية، بدون تضمينات.

## ٤. الأوامر التي يجب على المشغل تشغيلها قبل التدريب

```bash

# 3. التحقق من حزمة عرض المشغل
make corpus-retrieval-operator-demo-pack-validate

# 4. اختبار الدخان لحزمة عرض المشغل
make corpus-retrieval-operator-demo-pack-smoke

# 5. التحقق من سيناريوهات العرض
make corpus-retrieval-demo-scenarios-validate

# 6. اختبار الدخان لسيناريوهات العرض
make corpus-retrieval-demo-scenarios-smoke
```

## ٥. ما يمكن للمشغل عرضه بأمان

- استرجاع سجلات قانونية عربية بناءً على استعلامات معجمية
- حزم سياق منظمة (JSON + Markdown) جاهزة للخطوات المستقبلية
- قوالب طلبات آمنة مع قواعد صارمة
- فحص استشهادات ميكانيكي للإشارات في مسودة نص
- سير عمل متكامل من الاستعلام إلى الطلب في أمر واحد
- ٦ سيناريوهات عرض عربية تغطي حالات مختلفة (بحث عام، مرشح مسار، مرشح نوع سجل، نص كامل)

## ٦. ما لا يجب على المشغل ادعاؤه

- لا تقول "إجابة قانونية" — النظام لا يولد إجابات
- لا تقول "استشارة قانونية" — النظام لا يقدم استشارة
- لا تقول "ترجمة رسمية" — النظام لا يترجم
- لا تقول "تفسير قانوني" — النظام لا يفسر
- لا تقول "استنتاجات قانونية" — النظام لا يولد استنتاجات
- لا تقول "صحة قانونية" — النظام لا يحكم على الصحة
- لا تقول "دعم دلالي" — النظام لا يتحقق الدعم الدلالي
- لا تقول "إصدار عام" — النظام للعرض المحلي فقط

## ٧. سياسة المخرجات المولدة

- جميع مخرجات سير العمل تذهب إلى أدلة مؤقتة فقط (`/tmp/` أو دليل يحدده المستخدم)
- لا تُلتزم أي مخرجات مولدة في المستودع
- لا حزم سياق ملتزمة
- لا حزم طلب ملتزمة
- لا لقطات شاشة أو شرائح أو صفحات ويب أو فيديوهات أو مخرجات عامة
- شجرة العمل يجب أن تكون نظيفة باستثناء تغييرات التوثيق المقصودة

## ٨. الحدود القانونية والتقنية

- **المصدر العربي الرسمي هو الحاكم**
- **ليست استشارة قانونية**
- **ليست ترجمة رسمية**
- **لا تفسير قانوني**
- **لا استنتاجات قانونية مولدة**
- **لا حكم على الصحة القانونية**
- **لا تحقق الدعم الدلالي**
- **لا استدعاء نماذج لغوية (LLM)**
- **لا RAG (توليد معزز بالاسترجاع)**
- **لا إصدار عام**
- **مراجعة قانونية من مالك المستودع نشطة؛ المراجعة القانونية الخارجية اختيارية للاعتماد المؤسسي أو الرسمي**
