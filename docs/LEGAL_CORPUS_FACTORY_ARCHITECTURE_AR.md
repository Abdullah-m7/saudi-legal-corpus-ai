# معمارية مؤسسة النصوص القانونية السعودية متعددة اللغات (منتَج/مستودع)
# Multilingual Saudi Legal Corpus — Architecture (Repository/Product)

> **معمارية مستودع/منتَج قابلة لإعادة الاستخدام، لا مجرد إطار بحثي مستقبلي. المكوّنات الموسومة بـ«مستقبلي» غير منفّذة بالكامل في هذا الأساس. المصدر العربي الرسمي حاكم. لا ترجمة رسمية مُدّعاة. ليست استشارة قانونية.**

## نظرة عامة / Overview

هذا المستودع **منتَج بنية بيانات قانونية سعودية متعددة اللغات، جاهز للنماذج اللغوية، ومبني على مصادر رسمية**. يحوّل كل نظام إلى **طبقات آلية القراءة قابلة للتدقيق** تخدم الجهات الحكومية، وبُناة الذكاء الاصطناعي، والمؤسسات، والمستثمرين، والباحثين والمطوّرين، والمستخدمين العاديين. نظام الشركات هو **أول نظام مُنفَّذ**.

## طبقات البيانات / Data layers

- **المصدر العربي الرسمي (حاكم):** `data/official_arabic/…` (281 مادة).
- **الطبقة العربية الجاهزة للنماذج:** `data/official_arabic_legal_llm/…` (281).
- **الطبقة الإنجليزية (كامل + مرجع):** `data/official_english_legal_llm/…` (281) و`data/english_reference/…` (281).
- **الطبقة الصينية الداخلية:** مرشح قابل للعزل (189) + معالجات P0-001…P0-005 + مصادر مستخرجة (14) + قديم (5 ملفات/23 سجلًا). **طبقة لغوية واحدة**، ليست هوية المشروع، وليست رسمية/مُلزِمة/حاكمة.

## المكوّنات / Components

1. **ملفات تعريف الأنظمة / Law profiles** — تعريف قابل لإعادة الاستخدام لكل نظام (المصدر الرسمي، اللغات، الأعداد، أساس المصدر، نموذج مراجعة مالك المستودع والمراجعة الخارجية الاختيارية، حدود الطابع الرسمي). المخطط: `schemas/legal_corpus_factory/law_profile.schema.json`. **منفّذ:** ملف نظام الشركات.

2. **إعدادات الدفعات / Batch configs** — إدخال عام يصف دفعات المعالجة/المراجعة. المخطط: `schemas/legal_corpus_factory/batch_config.schema.json`. **مثال منفّذ:** P0-005 QA.

3. **جوازات مصدر المواد / Article provenance passports** — تتبع على مستوى المادة (المصدر الحاكم وبصمته، الطبقات المرجعية، الحالات، مسار المخاطر). المخطط: `schemas/legal_corpus_factory/provenance_passport.schema.json`. *(مخطط تأسيسي؛ التوليد الشامل مستقبلي.)*

4. **بنك المصطلحات / Terminology bank** — مرجع عربي-إنجليزي-صيني موحّد. **بذرة منفّذة** قيد مراجعة مالك المستودع النشطة.

5. **التحقق / Validation** — مدقّقات للأساس وللدفعات القائمة (قراءة فقط، عاملة على البصمات، قابلة لإعادة الإنتاج). *لا تُستبدَل المدقّقات الحالية في هذا الأساس.*

6. **جاهزية التصدير / Export readiness** — فصل واضح بين الداخلي/المرجعي والإصدار. *لا مخرجات إصدار عام في هذا الأساس.*

7. **جاهزية RAG/API مستقبلًا / Future RAG & API readiness** — *مستقبلي.* تصدير مُهيّأ للاسترجاع وواجهات برمجية، مع حفظ التسلسل والبصمات.

8. **إدماج أنظمة متعددة / Multi-law onboarding** — إضافة اللائحة التنفيذية لنظام الشركات وأنظمة سعودية أخرى بإعادة استخدام المخططات نفسها.

9. **توسّع متعدد اللغات / Multi-language expansion** — إضافة طبقات لغوية مرجعية أخرى ضمن التسلسل نفسه (العربية حاكمة).

10. **مراجعة مالك المستودع والمراجعة الخارجية الاختيارية / Repository & optional external review** — حالة مراجعة مالك المستودع النشطة حالة صريحة؛ المراجعة الخارجية اختيارية لاعتماد المؤسسات أو التبني الرسمي، لا شرط للاستخدام.

11. **فحوص الاتساق عبر الدفعات / Cross-batch consistency** — *مستقبلي.*

12. **كاشف التغيير/الإصدارات / Change–version detector** — *مستقبلي.*

## فئات المستخدمين / User groups

الجهات الحكومية · شركات الذكاء الاصطناعي وبُناة النماذج · المؤسسات والداخلون إلى السوق السعودية · المستثمرون · الباحثون والمطوّرون · المستخدمون العاديون.

## مسار الإدماج المستقبلي / Future onboarding path

- **اللائحة التنفيذية لنظام الشركات:** ملف تعريف + إعدادات دفعات + جوازات مصدر، بإعادة استخدام المخططات.
- **أنظمة سعودية أخرى:** نفس النمط، وبنك مصطلحات مشترك حيثما أمكن.

## حالة التنفيذ في هذا الأساس / Implementation status

- **منفّذ:** العقيدة، المعمارية، المخططات الثلاثة، ملف تعريف نظام الشركات، مثال إعداد دفعة (P0-005 QA)، بذرة المصطلحات، مدقّق الأساس + اختباراته.
- **مستقبلي:** المدقّقات العامة، مولّد التقارير، حزمة/واجهة RAG-API، فحوص الاتساق عبر الدفعات، كاشف التغيير، إدماج اللائحة التنفيذية.
