# معمارية مصنع النصوص القانونية القابل لإعادة الاستخدام (الأساس)
# Reusable Legal Corpus Factory — Architecture (Foundation)

> **هذا مستند معماري تأسيسي. المكوّنات الموصوفة أدناه مخطط مستقبلي؛ لا يُدّعى أن أيًّا منها منفّذ بالكامل في هذا الأساس ما لم يُذكر خلاف ذلك صراحةً. العربية حاكمة. ليست استشارة قانونية.**

## نظرة عامة / Overview

المصنع بنية قابلة لإعادة الاستخدام عبر أنظمة قانونية سعودية متعددة (نظام الشركات، ولائحته التنفيذية، وأنظمة أخرى مستقبلًا). يحوّل كل نظام إلى نصوص مُهيّأة للاسترجاع والنماذج اللغوية، مع حماية النص العربي الحاكم وقابلية التدقيق.

## المكوّنات / Components

1. **ملف تعريف النظام / Law profile** — يعرّف كل نظام (المعرّف، الاسم، الاختصاص، اللغة الحاكمة، اللغات المرجعية، عدد المواد، حالة المصدر الرسمي، ملفات المصدر، التسلسل القانوني، سياسة المراجعة، سياسة الإصدار). المخطط: `schemas/legal_corpus_factory/law_profile.schema.json`. **مثال منفّذ:** `data/legal_corpus_factory/law_profiles/sa_companies_law_m132_1443.profile.json`.

2. **إعداد الدفعة / Batch config** — إدخال عام يصف دفعة معالجة أو مراجعة (المعرّف، المرحلة، الأولوية، المسار، المواد، الأبواب المتوقعة وتوزيعها، أساس الترجمة، متطلبات الجودة والمراجعة البشرية، الادّعاءات المحظورة، الطبقات المحمية، سياسة التحقق). المخطط: `schemas/legal_corpus_factory/batch_config.schema.json`. **مثال منفّذ (P0-005 QA):** `data/legal_corpus_factory/batch_configs/...`.

3. **جواز مصدر المادة / Article provenance passport** — تتبع على مستوى المادة (المصدر الحاكم وبصمته، الطبقات المرجعية، حالات الاستخراج/المعالجة/الجودة/المراجعة البشرية، مسار المخاطر). المخطط: `schemas/legal_corpus_factory/provenance_passport.schema.json`. *(مخطط تأسيسي؛ التوليد الشامل لكل المواد عمل مستقبلي.)*

4. **بنك المصطلحات / Terminology bank** — مرجع مصطلحي عربي-إنجليزي-صيني موحّد. **بذرة منفّذة (محافظة، بانتظار المراجعة البشرية):** `data/legal_corpus_factory/terminology/...`.

5. **المدقّق العام للدفعات / Generic batch validator** — *مستقبلي.* لا يستبدل المدقّقات الحالية الخاصة بكل دفعة في هذا الأساس.

6. **المدقّق العام للجودة / Generic QA validator** — *مستقبلي.* لا يستبدل مدقّقات الجودة الحالية.

7. **مولّد التقارير / Report generator** — *مستقبلي.* لتوليد تقارير عربية موحّدة (hashes فقط) لكل دفعة.

8. **فصل الإصدار عن الداخلي / Release–internal split** — حدود واضحة بين ما هو داخلي/مرجعي وما هو قابل للإصدار. *لا تُنشأ أي مخرجات إصدار عام في هذا الأساس.*

9. **حزمة تصدير RAG/LLM / RAG-LLM export pack** — *مستقبلي.* تصدير مُهيّأ للاسترجاع مع حفظ التسلسل والبصمات.

10. **طابور المراجعة البشرية / Human review queue** — حالة صريحة مستقلة؛ لا يُعلَن اكتمالها إلا بقرار بشري. *يبقى `pending_human_legal_review`.*

11. **فحوص الاتساق عبر الدفعات / Cross-batch consistency checks** — *مستقبلي.* للتأكد من اتساق المصطلحات والأبواب والبصمات عبر الدفعات.

12. **كاشف التغيير/الإصدارات / Change–version detector** — *مستقبلي.* لرصد تغيّر النص الحاكم أو المصادر وربطه بـ `last_changed_commit`.

## مسار الإدماج المستقبلي / Future onboarding path

- **اللائحة التنفيذية لنظام الشركات:** ملف تعريف نظام جديد + إعدادات دفعات + جوازات مصدر، بإعادة استخدام المخططات نفسها.
- **أنظمة سعودية أخرى:** نفس النمط — ملف تعريف لكل نظام، وإعدادات دفعات، وبنك مصطلحات مشترك حيثما أمكن.

## حالة التنفيذ في هذا الأساس / Implementation status in this foundation

- **منفّذ:** العقيدة، المعمارية، مخططات (law_profile / batch_config / provenance_passport)، ملف تعريف نظام الشركات، مثال إعداد دفعة واحد (P0-005 QA)، بذرة مصطلحات، مدقّق تحقق للأساس + اختباراته.
- **غير منفّذ (عمل مستقبلي):** المدقّقات العامة، مولّد التقارير، حزمة RAG/LLM، فحوص الاتساق عبر الدفعات، كاشف التغيير، إدماج اللائحة التنفيذية.
